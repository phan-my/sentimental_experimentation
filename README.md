# 極東実験情　～ Sentimental Experimentation

Kyokutou Jikkenjou ~ Sentimental Experimentation is a unofficial fanwork based on Touhou Project by ZUN.

This game serves as a first step to my project to develop a bullet hell game engine.

This game was developed for Debian 13 x86_64 and derivative operating systems in C using SDL2.

## Installation
### Prereq
In Debian 13 or derivatives, install the following:  
``
apt install libglew-dev libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev libglm-dev libfreetype6-dev build-essential libgl1-mesa-dev libglew-dev libglfw3-dev libglu1-mesa-dev freeglut3-dev pkg-config cmake cmake-data libsdl2-dev
``

### Compiling
In the `src/` directory, type
``
make
``

Then run by typing
``
./omain.out
``
